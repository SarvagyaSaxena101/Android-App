# Android based Kitchen Helping Application
- A one in all kitchen solution application
  From, Finding Recipies, PLanning meals, Planning events, Cultural exploration or eat according to ur taste to planning your weekly meals according to your taste and a Calorie Counter.
  #Features
  1. It uses LLAMA 80b parameter LLM model as a chatbots and a RAG structure for custom Indian food exploration.
  2. Provides Youtube URLS for videos for any recipe that is known to mankind.
  3. Google Authenticatin using Firebase.

# Updates Coming Soon
1. Revamped UI
